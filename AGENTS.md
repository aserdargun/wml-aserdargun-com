# WML working contract

- Build the World Model Laboratory — an interactive bilingual (tr/en) 3D experiment surface where users observe, imagine, predict, act, and learn world models through Rapier physics, Three.js rendering, and hand-coded predictors. WFM is the research parent; WML is the experiment surface.
- Source of truth lives in `src/core/` (engine, observation, belief, models, metrics, scenarios, types), `src/visualization/` (Microverse stage, camera, bodies, future trails), `src/lessons/` and `src/education/` (World Model 101 chapters, term explanations, scenario prompts), `src/ui/` (controls, lenses, export), and `docs/` (ARCHITECTURE, SCIENTIFIC-INTEGRITY, WORLD-MODEL-ADAPTERS, WFM-INTEGRATION). WML is Vite 8 + React 19 + TypeScript 7 + `@react-three/fiber` + `@dimforge/rapier3d-compat`. The server uses port 5188 with `--strictPort`; do not displace another listener.
- Decision inputs: Rapier authoritative physics, hand-coded predictors (constant velocity, simple dynamics, biased dynamics), observation-derived belief, and scenario definitions. Observer outputs: forecast samples, measured error curves, branch histories, sampled sensitivity positions, and JSON evidence exports. Branch metadata and goal distance are recorded, not generated from unverified priors.
- World, scenario, predictor, model-comparison, branch, and export schema versions are explicit (`src/core/types.ts`, `src/core/models.ts`, `docs/WORLD-MODEL-ADAPTERS.md`). Update affected versions when semantics change. The robot is an assisted pusher proxy; grasping and wheel-ground control are abstracted.
- Every build writes `dist/release.json` with commit, build timestamp, and per-asset SHA-256 hashes. `npm run verify:artifact` validates the local artifact; `node scripts/verify-live.mjs https://<host> <sha>` validates the deployed artifact. Reject artifacts missing release metadata or with mismatched hashes.
- The Microverse uses its own palette (`theme-color: #f5f5f0` cream, soft shadows, contrasting studio backdrop). Do not use the public-family lime `#c8ff36`; do not load external 3D or lighting assets. Identified software renderers use lower pixel and shadow resolution to keep the experiment usable without a GPU.
- Keep Turkish and English controls, lesson chapters, term explanations, and scenario prompts equivalent. Model assumptions, units (metres, seconds, RMSE, goal distance) and freshness weight are labeled in both languages. Locale preference persists only when browser storage is available.
- Verify `npm test` (Vitest core), `npm run test:e2e` (Playwright acceptance), and `git diff --check` before handoff. Browser acceptance runs at 1440×1040 and 390×844; `WML_E2E_URL=<host>` reuses the suite against production. Camera changes, stage expansion and forecast-time inspection must preserve experiment clock, goal distance and branch count.
- Local work only unless the user authorizes external publication. Pushes to `main` flow through `.github/workflows/deploy-swa-wml-aserdargun-com.yml` to `swa-wml-aserdargun-com` in `rg-wml-aserdargun-com` (West Europe, Free SKU). Preserve unrelated work, in-memory snapshots (up to 451 per branch, six retained branches), and the strict-port dev server.
